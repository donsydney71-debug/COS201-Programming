# COS201 Programming I - Week 3 Practical Exercise

This repository contains the Java programming assignments for the Week 3 practical exercise.

## Included Files:
- `SimpleCalculator.java` - Performs basic arithmetic operations (addition, subtraction, multiplication, division).
- `AverageCalculator.java` - Calculates the average of three user-inputted numbers.
- `ItemCost.java` - Computes the total cost of an item based on quantity and unit price.
